How it's implemented

The can_ids package, one job per module

frame.py

CANFrame dataclass and the HCRL log parser.

simulator.py

14 simulated EV ECUs, HCRL replay, and the DoS / fuzzy / impersonation injector.

features.py

12 behavioural features, computed one frame at a time per CAN ID.

model.py

Isolation Forest, threshold calibration, learned rules, attack typing, explanations.

engine.py

The real-time loop: source → features → score → rules → alerts → stats.

alerts.py

Groups flagged frames into incidents; console, JSONL and webhook sinks.

dashboard/

Flask app pushing live state to the browser over Server-Sent Events.

cli.py

The four commands: dashboard, monitor, train, evaluate.

CAN frame → features.py → model.py → engine.py → alerts.py → dashboard · log · webhook
